Xuất bình luận / lead ra Excel

Chọn file JSON bình luận hoặc lead để lọc, trích liên hệ và tải Excel. Không cần API Revoland; thao tác này không thu thập bình luận Facebook hoặc tạo lead trên Revoland.

Tối đa 5 MB, 5.000 bản ghi, 20.000 ký tự mỗi bình luận. Trạng thái đồng bộ trong file là theo dữ liệu bạn nhập, không được xác minh qua API.
