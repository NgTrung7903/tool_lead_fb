# Dữ liệu QuinLand tùy chọn

File `quinland.json` trên máy phát triển chứa danh mục bất động sản và thông tin liên hệ thật, được loại khỏi Git.

Luồng nạp link Revoland, JSON và tự soạn sử dụng mã nguồn mà không cần file này. Khi chưa có dataset, mục kho QuinLand được ẩn.

Nếu công ty cần kho QuinLand, cung cấp riêng file JSON được phép sử dụng tại `resources/datasets/quinland.json`. Đối chiếu nguồn và quyền phân phối dữ liệu trước khi chia sẻ.

Kiểm thử và xác minh gói đầy đủ có kiểm tra kho 250 tin. Cần dataset nội bộ tương ứng để chạy trọn bộ kiểm tra đó và tái tạo bản EXE đầy đủ đã bàn giao.
